# Exhibit Sync — Windows Updates

Official portable Windows x64 releases of TSENEX Exhibit Sync.

Download the ZIP from [Releases](https://github.com/poolStackDeveloper/tsenex-exhibit-sync-updates/releases/latest), extract it to a writable local folder, and run `ExhibitSync.exe`.

A valid TSENEX serial key is required for playback. Online license activation uses the license-server URL supplied by your administrator. Offline license files can be activated without Internet access and are valid for three calendar months from first activation.

The application can check this repository for updates. Updates are authenticated with a signed manifest and SHA-256 and applied only after the operator confirms installation.

This repository contains release binaries, signed update metadata and this documentation. Application source, administrator tools, issuer private keys, customer records and serial keys are not published here.
